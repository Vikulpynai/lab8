## Этап 4. Классификация (премиум-сегмент аренды)

**Целевая переменная:** бинарный признак `is_premium = (price >= 300000)` — квартира относится к премиум-сегменту (от 300 000 тг/мес, верхний квартиль рынка, 23.8% объявлений). Из матрицы признаков исключены `price` и `price_m2`, чтобы предотвратить утечку данных.

**Цена ошибок для заказчика (агентства недвижимости / сервиса объявлений):**
* **FP (ложная тревога):** обычную квартиру ошибочно пометили как «премиум» и передали в премиум-подборку — клиент тратит время, снижается доверие к фильтру. На базовой модели: 7 случаев из 114 обычных квартир.
* **FN (пропуск):** реальную премиум-квартиру модель отнесла к обычному сегменту — агентство упустило высокомаржинальный объект (высокую комиссию). На базовой модели: 6 пропусков из 36 премиум-квартир (`precision = 30/37 = 0.811`, `recall = 30/36 = 0.833`).
* **Выбор порога:** поскольку упущенная премиум-сделка (FN) обходится дороже, чем ручная проверка лишнего объявления (FP), снижение порога до `0.38` по кросс-валидации оправдано: растёт полнота и итоговый `cv_f1` с `0.8531` до `0.8700`.
